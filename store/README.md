# Chrome Web Store submission

## Listing

**Name:** Scrimba Section Progress

**Short description:** Shows the current Scrimba section's progress beside the lesson timer.

**Description:**

See your current section's completion percentage, a compact progress bar, and estimated watched time beside the Scrimba lesson timer.

The extension reads the current lesson's immediate parent section. Estimated watched time is calculated from Scrimba's completion percentage and rounded section duration; it is not a measurement of actual viewing time.

When the outline's open/closed state can be determined, the extension briefly opens it to read section data. Otherwise, open the lesson outline manually to populate the badge. On narrow screens, the time estimate is hidden while the percentage and bar remain visible.

Works on Scrimba lesson pages where section progress is available. A Scrimba account and access to the relevant course may be required. This is an unofficial extension, not made by or affiliated with Scrimba.

No analytics, ads, separate extension account, remote code, or extension-initiated data transmission.

## Privacy tab

**Single purpose:** Display the current Scrimba lesson's parent-section completion percentage and estimated watched time beside the lesson timer.

**Site access justification:** The content script runs only on https://scrimba.com/* to read the lesson URL and section outline and insert the progress badge. It needs no additional extension API permissions.

**Remote code:** None. All executable code is included in the extension ZIP.

**Privacy policy:** Publish ../PRIVACY.md at a stable, publicly accessible URL and enter it in the dashboard. The local Markdown file is not a public policy URL. Disclose local processing of lesson URL paths and section names, durations, and completion percentages; the extension does not transmit or persist this information.

## Reviewer test instructions

1. Install the ZIP generated by `sh build.sh`.
2. Open a Scrimba lesson in a course you can access and refresh the page.
3. Find the badge beside the lesson timer. If it is absent, open the lesson outline to expose section progress.
4. Compare the badge percentage with the lesson's immediate parent section in the outline.
5. Switch lessons, manually open/close the outline, and use the keyboard while the outline is loading. Confirm the extension does not reopen or close a user-controlled panel.
6. Refresh the page and repeat. Resize the browser to check that the time summary hides below 700 pixels.

If reviewers need restricted course access, provide suitable test access through the dashboard's private test instructions. Do not put account credentials in this repository.
